# Stage 9: Asset Decisions

**Goal:** decide what visual and media assets each page needs, where they come
from, and who owns them — before writing begins.

## Asset register

One row per asset. Do not publish anything whose usage rights are unclear.

| Asset | Type | Page(s) | Source | Rights held | Optimised | Alt text |
|---|---|---|---|---|---|---|
| | photo / video / logo / icon / doc | | own / licensed / stock | | | |

## Photography

Real work photos outperform stock for local trade businesses, and they double
as E-E-A-T evidence.

- [ ] Hero image per core service page
- [ ] "What is included" or process photos
- [ ] Completed-project before/after where relevant
- [ ] Team photos (real people, with permission)
- [ ] Vehicle / premises / signage (supports local relevance)
- [ ] Consistent treatment — do not mix wildly different styles on one page

Do not use stock photos of an unrelated trade, and never use a stock image to
imply work the business has not done.

## Image technical requirements

- [ ] Descriptive alt text on every non-decorative image, 10–125 characters
- [ ] Decorative images use `alt=""` (not a keyword)
- [ ] Descriptive filenames (`marine-electrical-inspection-auckland.webp`)
- [ ] Compressed and sized appropriately; modern formats (WebP/AVIF)
- [ ] Dimensions set to prevent layout shift (CLS)
- [ ] Hero image preloaded and not lazy-loaded (LCP)

## Logo and brand assets

- [ ] Vector logo (SVG) plus raster fallbacks
- [ ] Favicon and touch icons
- [ ] Brand colours and fonts documented
- [ ] Correct usage of any partner / manufacturer logos (permission confirmed)

## Video

- [ ] Only where it genuinely helps (walkthroughs, testimonials)
- [ ] Hosted so it does not block page load
- [ ] `VideoObject` schema where a video is a primary page asset

## Documents

Quotes, brochures, spec sheets — keep the number low and make sure they are
current. A downloadable PDF with an old price is an accuracy liability.

## Output

A complete asset register: what is needed, who supplies it, rights status, and
optimisation state.
