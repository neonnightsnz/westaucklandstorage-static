### Content outline

A strong local service page usually runs in this order:

1. Service + location in the heading
2. The customer problem being solved
3. What the business does
4. Who the service is for
5. What is included
6. Why customers should trust the business
7. Relevant project evidence or photos
8. FAQs
9. A clear enquiry or booking action

Adapt the order for other page types — but every page needs a clear purpose,
proof, and one primary action.

| H1 | One per page, includes service + location where natural | |
| OG title / description | May differ from the meta tags for social sharing | |

> **Templated-metadata gate.** "Unique per page" is necessary but not
> sufficient. Opening every description with the page title and closing on a
> stock CTA ("Try it free now.", "Get a quote today!") is one generated shape,
> and duplicated or templated metadata site-wide is a documented content-quality
> problem even when the body copy is entirely original. Write a CTA for *this*
> page.
