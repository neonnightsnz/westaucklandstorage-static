# Website Strategy Framework

The canonical, client-agnostic framework for planning a local service business's
website and SEO strategy. Each client project copies this framework whole and
supplies its own business facts; this repository never holds client-specific
content.

## Language

### Structure

**Framework**:
The complete set of stage documents and references in this repository. Copied
whole into a client project as the starting point.
_Avoid_: Kit, boilerplate, starter pack

**Client project**:
A website project that has copied the Framework and supplies its own business
facts, research and completed worksheets.
_Avoid_: Instance, deployment, site

**Stage**:
A numbered unit of work (01–12) that produces a specific artefact carried into
later stages.
_Avoid_: Step, phase

### Local SEO

**Service area**:
The geographic area a business genuinely serves.
_Avoid_: Location, region, territory

**Location page**:
An SEO landing page targeting one service/location combination.
_Avoid_: Service-area page, city page, location landing page

### Programmatic SEO

**Playbook**:
A named pattern pairing a repeating query shape with the value each generated
page must deliver.
_Avoid_: Recipe, formula

**Hub**:
The single index page listing and linking to every page in a scaled section.
_Avoid_: Index page, category page

**Spoke**:
An individual page within a scaled section, linked from its Hub.
_Avoid_: Child page, leaf page

**Uniqueness test**:
The four-part check a generated page must pass before publication.
_Avoid_: Quality check

### Governance

**Gate**:
A hard rule with a threshold that warns on or blocks a design decision.
_Avoid_: Rule, checkpoint

**Unverified**:
A fact asserted but not yet confirmed by the business owner, and therefore not
publishable.
_Avoid_: Assumption, TBC
