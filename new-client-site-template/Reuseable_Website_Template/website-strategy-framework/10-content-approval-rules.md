# Stage 10: Content Approval Rules

**Goal:** nothing publishes without owner verification, and nothing drifts out
of date afterwards.

## Roles

- **Writer** — drafts against the Stage 5 brief
- **Technical reviewer** — confirms trade accuracy
- **Owner** — confirms business facts and claims
- **Approver** — final sign-off (may be the owner)

## What the owner must confirm in writing

Do not publish until each of these is confirmed:

- [ ] Services offered, and services explicitly not offered
- [ ] Service area — every location named
- [ ] Phone number, email, address, opening hours
- [ ] Licences, certifications and memberships (with current expiry)
- [ ] Guarantees and warranties, in the exact words used
- [ ] Any rating, review count or response-time claim
- [ ] Testimonials and customer names — and permission to use them
- [ ] Pricing statements or "from" prices
- [ ] Any manufacturer / dealer / partner status
- [ ] Photos — ownership and permission

## Verification log

Keep a dated record so claims can be re-checked:

| Claim | Location on site | Confirmed by | Date | Re-check due |
|---|---|---|---|---|
| | | | | |

## Approval workflow

1. Draft written against the brief
2. Technical review for accuracy
3. Owner review of all claims, names, numbers and locations
4. Marketing review of tone and metadata
5. Final approval recorded, with date
6. Publish

## Accuracy review cycle

| Content | Review frequency |
|---|---|
| Prices, offers, availability | Monthly |
| Opening hours, phone numbers, staff | Quarterly |
| Services and service area | Quarterly |
| Certifications, licences, memberships | On expiry and annually |
| Testimonials and permissions | Annually |
| Regulations and product information | When they change, minimum annually |
| Forms, links, tracking | Quarterly |

Recurring review checklist:

- [ ] No outdated services
- [ ] Service areas accurate
- [ ] Phone numbers current
- [ ] Opening hours current
- [ ] No expired offers
- [ ] No unsupported claims
- [ ] Forms submitting correctly (test them)
- [ ] No broken links
- [ ] Project details accurate
- [ ] Regulations / product info current
- [ ] Testimonials still permitted

> **Rule:** treat historical website content as evidence to verify, never as
> automatically current truth. A fact was true when it was written — that is
> not the same as true today.

## Change control

Record every significant edit so drift can be detected:

| Date | Page | Change | Reason | By |
|---|---|---|---|---|
| | | | | |

Updating a page that already has visibility is usually higher-value than
publishing a new one. Log the change so its effect can be measured.
