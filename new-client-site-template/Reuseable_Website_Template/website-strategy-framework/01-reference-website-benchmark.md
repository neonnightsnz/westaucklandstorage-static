# Stage 1: Reference Website Benchmark

**Goal:** understand what good looks like in *this* industry and market before
you plan anything. You are extracting reasoning and patterns — never copy.

## Step 1: Choose the references

Pick 3–5 sites. A useful set is:

- [ ] 2 direct local competitors ranking in the map pack
- [ ] 1 national or international leader in the same trade
- [ ] 1 well-executed local business outside the trade (design/UX reference)

Record each: URL, business name, trade, market, why it was chosen.

## Step 2: Benchmark each reference

For every reference site, capture:

| Question | Notes |
|---|---|
| What is their primary GBP category? | |
| What core services do they lead with? | |
| What page types do they have? | |
| Which locations / service areas do they claim? | |
| What is their primary CTA on each page type? | |
| How do they prove trust? (reviews, badges, guarantees, photos) | |
| What is their tone — trade, corporate, friendly, technical? | |
| What section order does their best service page use? | |
| What schema types are present? | |
| How fast does their mobile page feel? | |

## Step 3: Extract patterns, not words

For each reference, write:

- **Pattern worth adapting:** the structural/strategic idea and *why* it works
- **Pattern to avoid:** the thing they do badly, and the reason
- **Gap we can own:** what no reference does well for their customers

> **Rule:** never lift sentences, testimonials, statistics, certifications or
> claims. If you cannot explain *why* a reference does something, you cannot
> safely adapt it.

## Step 4: Note the anti-patterns

Common local-market failures to explicitly check for across the references:

- Keyword-stuffed suburb lists with no genuine service there
- "Welcome to [Business]" homepages with no clear offer
- Service pages under 400 words with no proof
- Contact forms with 9+ required fields
- Identical copy reused across location pages
- Claims of certifications or guarantees with no evidence
- Stock photography on a trade where real work photos would sell better

## Output

A one-page benchmark summary: 3–5 references, patterns to adapt, patterns to
avoid, and the gap this client can own.
