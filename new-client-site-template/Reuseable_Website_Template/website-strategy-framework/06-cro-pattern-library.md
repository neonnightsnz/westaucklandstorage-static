# Stage 6: CRO Pattern Library

**Goal:** make it easy for the right visitor to take the right next step.
Traffic without conversion is a cost, not an asset.

## Match the action to the intent

| Visitor intent | Primary action | What to avoid |
|---|---|---|
| Urgent local ("emergency electrician near me") | Tap-to-call, visible immediately | Multi-field forms, chat widgets |
| Local service ("marine electrician Auckland") | Call **or** short quote form | Burying the phone number |
| Commercial investigation ("best…") | Comparison content → soft CTA | Hard sell before proof |
| Informational ("how does… work") | Related service CTA, newsletter at most | Interrupting with a popup |
| Navigational (brand search) | Contact details, hours, map | Making them hunt |

An informational article may invite a related service enquiry. An urgent-service
page should prioritise a phone call. One page, one primary action.

## Conversion elements by page type

### Homepage
- [ ] Service + location clear within the first screen
- [ ] Phone number clickable on mobile
- [ ] One primary CTA repeated at top, middle and end
- [ ] Trust strip: reviews, years trading, licences
- [ ] Links to each core service

### Service page
- [ ] Service + location in the H1
- [ ] What is included, in plain language
- [ ] Proof: photos of real work, reviews
- [ ] FAQs answering real objections
- [ ] CTA at natural decision points

### Location page
- [ ] Confirmation you actually serve this area
- [ ] Local projects or testimonials
- [ ] Travel / callout details
- [ ] Same CTA pattern as the service page

### Contact / quote page
- [ ] Phone, email and form all available
- [ ] Minimum viable form fields
- [ ] Confirmation of what happens next, and when
- [ ] Opening hours and service area visible

## Form friction checklist

- [ ] Only ask for what you need to respond (name, contact, brief description)
- [ ] No required field the business will not use
- [ ] Mobile-friendly input types (`tel`, `email`)
- [ ] Inline validation, clear error messages
- [ ] Spam protection that does not add friction (honeypot before CAPTCHA)
- [ ] Confirmation screen with a real expectation of response time

## Measuring conversion

Set these up before launch so Stage 11 is possible from month one:

- [ ] Call clicks (mobile `tel:` events)
- [ ] Form starts vs. form completions (abandonment rate)
- [ ] Email clicks
- [ ] Direction requests via Google Business Profile
- [ ] Enquiry source attribution

> Only publish response-time promises the owner has confirmed. An unverified
> "we reply within 1 hour" is both an SEO trust risk and a customer-service
> liability.
