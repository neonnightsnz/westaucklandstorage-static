# Reference material

- `design/`: primary visual target selected by the user. Start with its README and saved HTML.
- `wordpress/`: canonical WordPress mirror for `npm run import:blog`. Preserve relative paths inside this folder; the importer reads archive pages, original articles and uploaded images here.

Neither directory is published. The application ships curated content from `src/data/` and assets from `public/`. Historical duplicates and unused originals are in the external archive documented in `docs/cleanup-archive.md`.
