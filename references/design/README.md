# Redesign reference

`West-Auckland-Storage.html` is the saved design selected by the user as the primary visual reference. Its supporting saved assets are included alongside it so remote agents can use it after cloning the repository.

Open the HTML file directly in a browser. The hero image uses the included `boat-trailer.jpg`; other images use the adjacent saved-assets folder. Google Fonts still requires an internet connection. This is a static visual reference, not a functional copy of the application.

The original inline design CSS and page markup are preserved. Development scripts and the injected Replit badge were removed, and the hero and favicon paths were made relative for local viewing. Current business facts and working application behaviour take precedence over historical reference copy.

These files intentionally live outside `public/`, so Astro does not publish them.
