West Auckland Storage design system
Use this design system before authoring new West Auckland Storage UI.

Source of truth
Import ../../tokens.css for the color, typography, spacing, layout, and motion tokens.
Use the component class names and patterns demonstrated at /design-system/.
Use real yard, boat, caravan, trailer, or vehicle photography where imagery is needed.
Keep the visual language practical, sturdy, maritime, local, and unpretentious.
Typography
Use Barlow Condensed for display headings, labels that need emphasis, and numeric marks.
Use DM Sans for body copy, navigation, form controls, and supporting text.
Display headings are uppercase, tightly tracked, and allowed to wrap across short lines.
Body copy should stay direct, readable, and conversational.
Color
Use --wast-blue as the primary marine blue.
Use --wast-blue-bright for calls to action, accents, focus states, and small markers.
Use --wast-blue-light for secondary emphasis on dark backgrounds.
Use the neutral tokens for surfaces, rules, and text.
Do not introduce decorative golds, greens, reds, gradients, or luxury-marina colors.
Components
Prefer square or nearly square controls with clear borders.
Use a bright blue filled button for the primary action.
Use an outlined light button on dark sections.
Use text links with a directional arrow for secondary actions.
Keep cards simple: real imagery, clear headings, and useful copy.
Keep focus states visible and maintain the existing skip-link pattern.
Content and imagery
Lead with the guest need, then the real difference, then the easy next step.
Prefer “close to home”, “secure”, “straightforward”, “no fuss”, “your spot”, and “sorted”.
Avoid corporate storage language, luxury-marina claims, and unverified security or undercover-storage promises.
Describe slipway access conditionally when the current operational status is not confirmed.
Before shipping
Check that the new UI:

Uses the tokens rather than inventing a parallel palette.
Works on narrow screens without hiding key actions.
Has visible keyboard focus and readable contrast.
Uses honest facility language.
Feels like a real working West Auckland boat yard rather than a generic storage template.
